<ul>
	<li>Gary T. Leavens, <em>Introduction to Aspect-Oriented Programming and its Reasoning Problems
</em>Based on joint work with Curtis C. Clifton, James Noble, Hridesh Rajan.  [<a href="http://research.microsoft.com/en-us/um/people/leino/IFIP-WG2.3/media/48/Leavens-ConcerningReasoning.ppsx">slides</a>]How to modularize code in the face of cross-cutting concerns is a pressing problem for large software systems. Aspect-oriented languages, such as AspectJ, help solve this problem by allowingadditions and changes to a program's execution. However, efficient reasoning about the functional behavior of AspectJ code difficult. In this talk I will introduce: the design and programming problems addressed by aspect-oriented techniques, the solutions adopted by aspect-oriented languages (in particular by AspectJ), and some of the problems that such solutions cause for efficient reasoning. After describing these problems, I will give an overview of various techniques for solving them, including some of my own work.
This talk in part describes joint work with Curtis Clifton, James Noble, and Hridesh Rajan and is based on work described in Clifton's Ph.D. dissertation. That work was supported in part by the US NSF under grants CCF-04-8078 and CNS 08-08913. For more details see <a href="http://www.eecs.ucf.edu/~leavens/modular-aop/">http://www.eecs.ucf.edu/~leavens/modular-aop/</a></li>
